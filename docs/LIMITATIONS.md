# Limitations (Phase 1.5)

- **Demo only**: Synthetic benchmarks, not operational NWP.
- **Single cycle**: 00 UTC demo cycle; multi-cycle lagged ensembles deferred to Phase 2.
- **Grid**: Full 0.25° domain contract with reduced demo subset for fast interaction.
- **Precipitation**: Deterministic weighted blend; Vincentized quantile blending deferred.
- **Uncertainty**: Not split-conformal calibrated; do not interpret as 95% CI.
- **Regimes**: Rule-based soft probabilities, not unsupervised clustering.
- **Authentication**: None (local/demo deployment).
- **Warnings**: Forecast guidance only — not an official warning service.
- **Claims**: SYNTHESIS superiority over any model requires measured verification; the UI does not auto-claim wins.
